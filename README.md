## Introduction

### Fairness Extension for PipeGenie AutoML

PipeGenie-Fairness extends the PipeGenie AutoML framework with fairness-aware machine learning techniques.

The project integrates fairness mitigation and evaluation methods into PipeGenie's evolutionary pipeline generation process, allowing users to assess and reduce algorithmic bias while maintaining predictive performance.

## Features

### Fairness Preprocessing

Mitigate bias before model training through data balancing and sensitive feature handling.

### Fairness In-processing


Mitigate bias during the ensemble construction phase by introducing a fairness-aware voting strategy.

Instead of relying solely on the standard PipeGenie voting mechanism, the proposed approach computes a weight for every estimator according to both:

- predictive performance;
- fairness performance.

The contribution of each objective is controlled through the **alpha** parameter.

### Fairness Postprocessing

Apply Fairlearn-based mitigation techniques to pipelines generated by PipeGenie.

Current implementation includes:

- Fairlearn GridSearch
- Automatic mitigation of ensemble estimators
- Best mitigator selection based on validation performance

### Fairness Evaluation

Generate fairness reports using:

- Balanced Accuracy
- Equalized Odds Difference
- Demographic Parity Difference
- Group-wise performance metrics

### Supported Tasks

- Classification
- Regression

Move into the project directory:

```

```

Create a virtual environment:

```
python -m venv .venv
```

Activate it:

Windows

```
.venv\Scripts\activate
```

Linux / macOS

```
source .venv/bin/activate
```

Install dependencies:

```
pip install -r requirements.txt
```

## Usage

> **Note:**  
> The helper function `prepare_data()` (located in `Utils/preparation.py`) is provided for the **regression tutorials** to simplify dataset preparation and sensitive feature handling. It is not required for classification workflows.

### Fairness Preprocessing

```
from Preprocessing.preprocessing import fairness_preprocessing

X_train_fair, y_train_fair = fairness_preprocessing(
    X_train,
    y_train,
    sensitive_features
)
```

### Fairness Inprocessing

## Fairness Inprocessing

Enable fairness-aware voting directly when creating a PipeGenie model.

### Classification

```python
from pipegenie.classification import PipegenieClassifier

model = PipegenieClassifier(
    grammar=grammar_file,
    generations=5,
    pop_size=50,
    elite_size=5,
    seed=42,
    fair_voting=True,
    alpha=0.6,               #Trade-off between predictive performance and fairness
)
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

### Regression

```python
from pipegenie.regression import PipegenieRegressor

model = PipegenieRegressor(
    grammar=grammar_file,
    generations=5,
    pop_size=50,
    elite_size=5,
    seed=42,
    fair_voting=True,
    alpha=0.6,
)

model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

### Fairness Postprocessing

```
from postprocessing.postprocessing import fairness_postprocessing
from postprocessing.preprediction import select_best_mitigator

fair_estimators = fairness_postprocessing(
    ensemble=model.ensemble,
    X_train=X_train,
    y_train=y_train,
    sensitive_features=A_train
)

best_name, best_mitigator, best_score = select_best_mitigator(
    fair_estimators,
    X_validation,
    y_validation
)
```

### Fairness Report

```
from pipegenie.fairness import fairness_report

report = fairness_report(
    y_true=y_test,
    y_pred=y_pred,
    sensitive_features=A_test
)
```
